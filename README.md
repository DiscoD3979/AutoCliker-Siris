# AutoCliker-Siris

Простой автокликер для Windows: один файл, ничего ставить не нужно. Исходники открыты — вся программа на C++20, без библиотек и без «сюрпризов».

## Что умеет

- **Интервал кликов** — задаётся в часах, минутах, секундах и миллисекундах. Можно хоть 1 мс, можно хоть раз в час.
- **Случайный интервал** — диапазон от/до в миллисекундах, чтобы клики не шли ровно как метроном.
- **Кнопка** — левая, правая, средняя.
- **Тип клика** — одиночный, двойной, тройной или удержание (зажал и держит).
- **Позиция** — клик туда, где стоит курсор, или в фиксированную точку экрана (выбирается кнопкой «Выбрать» — просто нажмите в нужное место).
- **Режим** — бесконечно, N кликов или N секунд работы.
- **Задержка перед стартом** — если нужно успеть переключиться на игру.
- **Горячая клавиша** — по умолчанию F6: старт/стоп. Меняется кликом по полю.
- **Счётчик кликов** и индикатор работы внизу окна.
- **Настройки сохраняются** в `AutoCliker-Siris.ini` рядом с exe — закрыл, открыл, всё на месте.

## Как пользоваться

1. Запустите `AutoCliker-Siris.exe`.
2. Выставите интервал, кнопку и режим.
3. **СТАРТ** (или F6) — поехали. **СТОП** (или F6) — стоп.
4. Чтобы кликать в одну точку — включите «Клик в фиксированной точке» и нажмите «Выбрать»: окно скроется, кликните в нужное место экрана, Esc — отмена.

## Сборка из исходников

Нужны Visual Studio (MSVC), LLVM/Clang, CMake и Ninja. Дальше:

```bat
build.bat
```

Готовый exe: `build\AutoCliker-Siris.exe`. Это статическая сборка — рядом не нужно никаких DLL.
