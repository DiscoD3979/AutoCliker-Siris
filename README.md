# AutoCliker-Siris

Мощный автокликер для Windows на чистом C++20 (Win32 + GDI+), без внешних зависимостей и без вирусов — исходники открыты, всё видно.

Тёмная тема «чёрный + жёлтый», интерфейс полностью кастомный (GDI+, сглаживание).

## Возможности

- **Скорость до 1000 кликов/сек** — логарифмический слайдер, точность 1 мс (QueryPerformanceCounter + timeBeginPeriod)
- **Случайный интервал** — диапазон мин/макс в мс, чтобы не палить бота
- **Кнопка:** ЛКМ / ПКМ / средняя
- **Тип клика:** одинарный / двойной / тройной / удержание (зажать и держать)
- **Режим:** бесконечно или N кликов
- **Горячая клавиша** — настраивается кликом по полю (по умолчанию F6, старт/стоп)
- **Счётчик кликов** и пульсирующий индикатор работы
- **Сохранение настроек** в `AutoCliker-Siris.ini` рядом с exe
- Клики через `SendInput` — работают в любых играх и программах

## Сборка

Требуется Visual Studio (MSVC) + LLVM/Clang + CMake + Ninja.

```bat
build.bat
```

Или вручную:

```bat
call "D:\Visual code\VC\Auxiliary\Build\vcvarsall.bat" x64
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_COMPILER=D:/LLVM/bin/clang-cl.exe
cmake --build build
```

Результат: `build\AutoCliker-Siris.exe` — один файл, ничего не требует.

## Использование

1. Выставьте скорость, кнопку, тип клика
2. Нажмите **СТАРТ** (или F6)
3. **СТОП** / F6 — остановить

## Структура

```
src/
  main.cpp      — точка входа, GDI+ init
  ui.cpp        — окно, отрисовка, обработка мыши/клавиатуры
  clicker.cpp   — движок кликов (SendInput, высокоточный таймер)
  settings.cpp  — INI-сохранение настроек
  theme.h       — палитра (чёрный/жёлтый)
```
